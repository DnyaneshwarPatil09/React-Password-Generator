# Password Generator

A clean, modern React application for generating secure, customizable, and random passwords.

## Features

- Custom password length slider (6 to 32 characters)
- Toggle options for Uppercase, Lowercase, Numbers, and Symbols
- Live password strength indicator (Weak, Medium, Strong, Very Strong)
- One-click copy to clipboard with toast notification
- Dark mode responsive UI

## Tech Stack

- React
- JavaScript (ES6+)
- CSS3
- FontAwesome Icons
- React Toastify

## Getting Started

### Installation

```bash
npm install
```

### Run the Project

```bash
npm run dev
# or
npm start
```

### Build for Production

```bash
npm run build
```
